# 🤖 AI Chatbox

## 📌 Project Description

AI Chatbox is a simple and interactive web-based chatbot application designed to provide users with an engaging conversational experience. It offers a clean, user-friendly interface where users can interact with an AI chatbot by sending messages and receiving responses.

The project is developed using HTML, CSS, and JavaScript, focusing on responsive design, interactive elements, and smooth user interaction.

## ✨ Features

- Interactive chatbot interface.
- Send and receive messages.
- User-friendly and clean UI.
- Responsive web design.
- Real-time message display.
- Simple and easy-to-use interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Chat functionality and interactivity.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/satyamk4153-cmd/Ai-chatbox.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start interacting with the chatbot.
